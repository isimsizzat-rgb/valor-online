# Valor Online

Web oyun prototipi. Görseller `assets/images/` klasöründe ayrı dosyalar olarak tutulur; oyun kodu `index.html` içindedir.

GitHub Pages için `main` dalı ve `/(root)` klasörü seçilmelidir.

## Arayüz

Yeni bordo/parşömen düzeni `assets/ui/crimson*` dosyalarındadır. Alt gezinme: Çanta, Menü, Anasayfa, Profil, Sohbet. Menü mevcut sayfalara ve canlı oyun işlemlerine bağlanır; örnek karakter veya sohbet verisi içermez.

Ayarlar → Arayüz düzeni → Klasik görünüm ile önceki tasarıma dönülür. Bu tercih `valor-layout-v2` altında tutulur; karakter kaydına dokunmaz. Aydınlık/Karanlık/Oto seçim bağımsız kalır. Kaydedilmiş renk tercihi yoksa aydınlık açılır.
